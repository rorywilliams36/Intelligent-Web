# Intelligent-Web

Project completed for the Intelligent Web module by Benjamin Tindal & Rory Williams

## Installation

It is recommended you run the code in this order:

1. Ensure your node.js version is up to date
2. Run `npm install` to install all required packages
3. Run `npm start` to run the program (defaults to `locahost:3000`)

Once up and running the app can also be ran as a PWA on mobile and laptop devices, it has its own custom splashscreen & icons.

## Important Pages

- Use `/login` to sign in, allowing you to comment/submit plants
- Use `/all_plants` to view all of the plants posted by the commnuity
- Use `/create_plant` to submit a new plant
- Use `/plant/:id` to view a particular plant, its location and associated details.
